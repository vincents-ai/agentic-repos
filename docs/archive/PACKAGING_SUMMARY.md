## Configuration

### Skylet Config (skylet-config.yaml)

```yaml
plugins:
  # Storage backend (load first)
  - name: garage-s3
    path: ./plugins/garage-s3/libgarage_s3.so
    enabled: true
    priority: 10
    config:
      auto_start_garage: true
      data_dir: "./data/garage"
      s3_port: 3900

  # Git operations (load second)
  - name: git-operations
    path: ./plugins/agentic-repos/libagentic_repos.so
    enabled: true
    priority: 5
    config:
      storage.default_backend: "garage-s3"
      lfs.enabled: true
```

### Environment Variables (agentic-repos.env)

```bash
# Storage
export REPOS_STORAGE_BACKEND="local"  # or "s3"
export REPOS_STORAGE_PATH="./data/repos"

# S3 (when using garage-s3)
export GARAGE_ENDPOINT="http://localhost:3900"
export GARAGE_ACCESS_KEY_ID="garage"
export GARAGE_SECRET_ACCESS_KEY="garage"

# LFS
export REPOS_LFS_ENABLED=true
export REPOS_LFS_BASE_URL="http://localhost:8080"
```

## Deployment Scenarios

### Scenario 1: Local Storage (Simplest)

```bash
# Use local filesystem for storage
export REPOS_STORAGE_BACKEND="local"
export REPOS_STORAGE_PATH="./data/repos"
```

**Pros**: Simple, no dependencies
**Cons**: No distributed storage, limited scalability

### Scenario 2: S3 Storage with Embedded Garage

```bash
# Use embedded Garage for S3 storage
export REPOS_STORAGE_BACKEND="s3"
export GARAGE_ENDPOINT="http://localhost:3900"
```

**Pros**: S3-compatible, embedded, easy setup
**Cons**: Single-node Garage, not distributed

### Scenario 3: S3 Storage with External Garage Cluster

```bash
# Use external Garage cluster
export REPOS_STORAGE_BACKEND="s3"
export GARAGE_ENDPOINT="http://garage-cluster:3900"
export GARAGE_ACCESS_KEY_ID="${CLUSTER_ACCESS_KEY}"
export GARAGE_SECRET_ACCESS_KEY="${CLUSTER_SECRET_KEY}"
```

**Pros**: Distributed, scalable, production-ready
**Cons**: Requires external Garage deployment

## Integration Points

### 1. Plugin Loading

Skylet loads plugins in priority order:
1. garage-s3 (priority: 10) - starts Garage, registers S3 service
2. agentic-repos (priority: 5) - discovers S3 service, uses for storage

### 2. Service Registry

garage-s3 registers in global registry:
```rust
global_registry().register(
    s3_backend,
    None,  // available to all tenants
    true,  // is default
    0      // priority
);
```

agentic-repos queries registry:
```rust
let backend = global_registry().get_default();
// or
let backend = global_registry().get_for_tenant("tenant-id");
```

### 3. Storage Operations

Git operations use storage backend:
- Repository storage: `{tenant_id}/repos/{repo_name}.git`
- LFS storage: `{tenant_id}/lfs/objects/{oid}`

## Troubleshooting

### Plugin Not Loading

```bash
# Check dependencies
ldd plugins/libagentic_repos.so

# Check permissions
chmod +x plugins/*.so

# Check logs
tail -f ~/code/skylet/skylet.log
```

### S3 Connection Issues

```bash
# Check Garage is running
ps aux | grep garage

# Check S3 endpoint
curl http://localhost:3900/health

# Check environment
env | grep GARAGE
```

### Repository Operations Failing

```bash
# Enable debug logging
export REPOS_LOG_LEVEL="debug"

# Check storage path
ls -la ./data/repos/

# Check permissions
chmod -R 755 ./data/repos/
```
